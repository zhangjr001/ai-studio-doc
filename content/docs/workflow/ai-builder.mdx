面对复杂的业务场景，从零在空白画布上绘制节点、连线与配置参数可能会耗费大量时间。Spark AI Studio 内置了 **AI 构建助手（AI Builder）**，让你只需选择常用拓扑骨架或输入一段自然语言描述，系统即可一键生成工作流初稿。

![AI 构建抽屉界面](/images/workflow/ai-builder-drawer.png)

## 快速入口与预置骨架

在工作流编辑器顶栏点击 **Sparkles 图标**（或在空白画布引导中点击），右侧即可滑出「AI 构建」交互抽屉。系统默认提供了三种企业级高频拓扑骨架：

### 1. 单个智能体（Single Agent）
- **骨架形态**：`Start` → `Agent` → `End`
- **适用场景**：轻量级单点问答、简单的文本摘要、翻译或单个专业角色的咨询机器人。
- **特点**：零配置分支，链路最短，响应最快。

### 2. 带护栏智能体（Guardrailed Agent）
- **骨架形态**：`Start` → `Rule Guardrail`（`pass` → `Agent` → `End`；`fail` → `End`）
- **适用场景**：对合规性与安全性有严格要求的企业级对外应用（如客户服务、官方渠道问答）。
- **特点**：先对用户输入进行长度截断、PII 隐私合规筛查以及注入攻击检测，过滤安全风险后再交由大模型处理。

### 3. 按意图分流（Intent Routing）
- **骨架形态**：`Start` → `Guardrail` → `分类 Agent` → `Router` → `多路垂直 Agent` → `End`
- **适用场景**：多业务交叉的复杂系统（如综合客服助手：分别负责「技术支持」、「订单查询」、「人工投诉」不同意图）。
- **特点**：由分类器负责识别意图并由 Router 精确分发，各垂直 Agent 专注独立领域并挂载对应知识库或工具。

## 自然语言交互式生成

除了使用上述三类预置模板外，你也可以在对话框中直接用自然语言描述具体诉求：

```text title="输入示例 1：汽车售后与保养问答"
帮我搭一个汽车 4S 店问答工作流：
1. 先检查用户输入是否包含电话等隐私，有的话拦截并提示风险；
2. 对提问做分类：如果是保养、故障相关问题，调用车辆手册知识库；如果是购车优惠或问候，走通用问答；
3. 输出格式要求为 JSON，包含 answer 字段。
```

```text title="输入示例 2：代码审查助手"
构建一个代码 Review 工作流，输入代码文本，
先限制最大长度 4000 字，然后交由 Code Agent 审查代码规范、潜在 Bug 与性能瓶颈，
最后格式化输出结果。
```

### 生成与自动排版
1. AI 助手解析输入意图，并在几秒内自动在画布上实例化对应的 `Start`、`Rule Guardrail`、`Agent`、`Router` 与 `End` 节点；
2. 自动根据上游字段建立连线与数据流映射；
3. 点击顶栏的 **自动整理（Layout）** 按钮，系统基于 DAG 拓扑算法瞬间完成横向或纵向的美观对齐。

## 最佳实践

- **结合预置模板做起点**：对于常规需求，推荐先点击「带护栏」或「按意图分流」骨架打好地基，再进行细节微调；
- **核对大模型与工具绑定**：AI 生成的 Agent 节点会自动使用当前项目默认的对话模型。如果某些节点需要特定模型（如强推理模型进行复杂分类）或特定的知识库工具，请点击该节点并在右侧属性面板完成选定；
- **及时点击发布生成版本**：AI 构建出的工作流处于 `草稿` 状态，验证通过后点击右上角的「发布」即可上线稳定版本。
