---

知识库（Knowledge Base）为工作流提供检索增强（RAG）能力：上传的文档经过解析、分块与向量化后，可以在 LLM 节点中被引用为上下文。

## 创建知识库

1. 进入项目下的「知识库」页面，点击**新建知识库**；
2. 填写名称与描述；
3. 选择**嵌入模型**（向量化用）与可选的**重排模型**；
4. 保存后进入知识库详情页，开始上传文档。

## 支持的内容形态

| 形态 | 处理方式 |
| ---- | -------- |
| PDF / Word / PPT / Excel / Markdown / 纯文本 | 文本抽取与结构化解析 |
| 图片（扫描件、截图） | OCR-VL 视觉模型解析为文本 |
| 音频 | Whisper 语音转写为文本 |

<Callout type="info">
  图片与音频的解析依赖在「模型管理」中配置的**多模态模型**。未配置时，对应类型文档会解析失败并在文档列表中标记错误。
</Callout>

## 与工作流结合

在 LLM 节点前串联**知识库检索**节点，把检索结果注入提示词：

```
开始 → 知识库检索 → LLM（提示词中引用检索结果）→ 结束
```

接下来：

- [上传与解析](/docs/knowledge/ingestion)：了解解析管线与失败排查；
- [分块与检索](/docs/knowledge/search)：调优检索质量的参数都在这里。
