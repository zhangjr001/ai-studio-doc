在复杂的 AI 应用研发中，提示词（Prompt）往往是决定模型输出效果的核心业务资产。将提示词硬编码在代码或散落在各个独立的画布节点中，极易导致调优困难、无法回滚以及跨流程复用成本高昂。

Spark AI Studio 将提示词提升为项目一等公民资产，提供统一的「提示词库」进行集中治理与协同迭代。

![提示词资产列表界面](/images/prompts/prompts-list.png)

## 提示词卡片与核心属性

进入项目的「提示词」页面，所有已创建的提示词以卡片形式整齐陈列：

- **名称与描述**：标明提示词的用途（如 `New agent system prompt`，描述：`简单聊天，10字以内`）；
- **分类标签（Tag）**：
  - `Agent 系统提示词`：为工作流中的智能体赋予角色、设定行为边界与对话语气；
  - `护栏规则`：专门用于指导安全判定模型的审校准则；
- **唯一标识标识符（Slug）**：系统自动生成的稳定短标识（如 `pmt_dt4l`、`pmt_7onp`），在工作流 DSL 和代码调用中以此唯一索引；
- **当前版本号**：展示当前激活的主版本（如 `v2`）；
- **操作者与时间**：详细记录由谁在何时创建或更新。

## 提示词编辑器与企业级版本管理

点击卡片进入提示词编辑工作台，系统提供代码编辑器与完善的版本管控右侧栏：

![提示词编辑器与版本追踪](/images/prompts/prompt-editor-versions.png)

### 1. 参数化模板语法
在编写提示词时，支持使用双大括号语法 `{{参数名}}` 声明动态占位变量：

```text title="提示词模板编写范例"
你是一名资深的 4S 店汽车售后顾问。请根据以下参考资料回答用户问题：

[参考资料]
{{context}}

[用户提问]
{{question}}

[回答规范]
1. 语言亲和专业，字数控制在 150 字以内；
2. 如果参考资料中没有提及，请礼貌告知无法回答，切勿捏造答案。
```

当工作流中的 Agent 节点引用该提示词时，系统会自动解析出 `context` 和 `question` 两个参数槽，并在节点面板中引导用户绑定上游输入或知识库工具输出。

### 2. 严格的不可变版本流水线（Immutable Versioning）
AI Studio 遵循金融级的版本审计标准：
- **追加式保存**：每次在编辑器中修改内容并点击「保存为新版本」时，系统会生成全新的版本号（如 `v1` → `v2` → `v3`）；
- **历史只读保护**：所有历史版本均被锁定为只读状态，不可原地篡改，确保任何一次线上运行的提示词都可以精准回溯复现；
- **版本切换与对比**：在右侧「版本历史」列表中，可随时点击任一历史版本查看当时的内容与发布时间。

### 3. 反向引用拓扑追踪（Impact Analysis）
在右侧面板的「引用」区域，系统自动展示全项目拓扑中当前正在引用此提示词的工作流与节点列表：

```
引用 (Reverse References)
└── 新建工作流 (agent-1793154559900) [↗]
```

- **影响面透明**：在更新提示词前，开发者可以明确预知改动将影响哪些线上工作流；
- **点击直达**：点击工作流名称旁的跳转图标，可直接跳转到对应的画布定位该智能体节点。

## 在工作流画布中引用与解绑

在工作流编辑器的 Agent 节点属性面板中：
- 点击「绑定提示词」，从弹出列表中勾选目标提示词模板，节点上即刻出现带 Slug 标识的紫色标签（如 `pmt_dt4l`）；
- 随时可点击标签旁边的 **Edit** 快速在新窗口中修改模板，或点击 **Unbind** 解绑还原为内联普通提示词。
