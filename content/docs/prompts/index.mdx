提示词库集中管理项目内的提示词模板。相比把提示词散落在各个节点里，统一管理带来三个好处：**复用**、**迭代有痕迹**、**非开发角色也能参与调优**。

## 创建提示词模板

1. 进入「提示词」页面，点击**新建提示词**；
2. 填写名称、分类标签与模板内容；
3. 在模板中使用 `{{参数名}}` 占位符声明变量：

   ```text title="模板示例：客服助手"
   你是 {{product}} 的客服助手。请严格根据以下资料回答用户问题，
   资料中没有的内容请如实说明无法回答。

   参考资料：
   {{context}}

   用户问题：{{question}}
   ```

4. 保存后即可在工作流的 LLM 节点中引用。

## 在工作流中引用

LLM 节点选择「引用提示词模板」后，节点配置面板会列出模板声明的参数，将上游变量（用户输入、检索结果等）绑定到对应参数即可。模板更新后，引用它的节点在下次运行时使用新版本。

## 在线调试

提示词详情页提供**调试**功能：

- 手动填入参数值，直接调用对话模型查看输出；
- 支持切换不同模型对比同一模板的效果；
- 调试满意后再发布，供工作流引用。

<Callout type="tip">
  把「角色设定、输出格式、边界约束」拆成多个小模板组合使用，比维护一个巨型提示词更容易迭代。
</Callout>
