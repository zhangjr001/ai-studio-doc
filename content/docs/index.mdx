欢迎来到 AI Studio 文档。AI Studio 让你在一个平台上完成 **AI 工作流编排、知识库构建、模型管理与运行观测**，支持私有化部署，数据完全留在自己的基础设施内。

## 核心能力

<Cards>
  <Card title="工作流编辑器" href="/docs/workflow" desc="画布式可视化编排，从简单对话到多步骤 Agent 流程。" />
  <Card title="知识库" href="/docs/knowledge" desc="上传文档自动解析、分块、向量化，支持多模态检索。" />
  <Card title="模型管理" href="/docs/models" desc="统一接入对话、嵌入、重排、多模态四类模型。" />
  <Card title="MCP 工具" href="/docs/integrations/mcp" desc="接入 Model Context Protocol，扩展 Agent 的工具能力。" />
  <Card title="提示词库" href="/docs/prompts" desc="团队共享的提示词模板，支持参数化与在线调试。" />
  <Card title="观测与评估" href="/docs/integrations/observability" desc="全链路 Trace、Token 用量与输出质量评估。" />
</Cards>

## 我该从哪里开始？

- **第一次使用**：从[快速开始](/docs/getting-started)入手，5 分钟跑起服务并创建第一个工作流。
- **想了解产品设计**：阅读[核心概念](/docs/concepts)，理解组织、项目、工作流与知识库之间的关系。
- **准备上线部署**：直接查看[部署指南](/docs/deployment)。
