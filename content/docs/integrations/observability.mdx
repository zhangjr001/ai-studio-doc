工作流上线只是开始。AI Studio 内置观测能力，帮助你回答三个问题：**跑没跑成功**、**花了多少成本**、**回答得好不好**。

## 运行记录与 Trace

每次工作流执行（无论是测试运行、共享聊天还是 API 调用）都会生成一条运行记录：

- **拓扑视图**：在画布上回放每个节点的执行顺序、耗时与状态；
- **节点详情**：点击节点查看该步骤的完整输入与输出；
- **错误定位**：失败节点高亮并展示错误堆栈，支持从中间节点重跑调试。

## 用量统计

- 按模型统计 Token 消耗与调用次数；
- 按工作流 / 时间维度聚合，评估成本趋势；
- 组织管理员可在平台控制台查看跨项目的汇总数据。

## 评估

对共享聊天与测试运行的输出，可以从两个层面做质量评估：

- **人工评估**：在运行记录中对回答标注满意 / 不满意，沉淀 bad case；
- **模型评估（LLM-as-a-Judge）**：配置一个评估模型与评分维度（准确性、相关性等），批量给历史运行打分，快速定位低质量回答。

<Callout type="tip">
  知识库内容更新、提示词调整、模型切换之后，建议用固定的评估集跑一轮回归，确认质量没有回退。
</Callout>
