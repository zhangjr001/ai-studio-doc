知识库（Knowledge Base）是 Spark AI Studio 提供检索增强生成（RAG）能力的核心基础设施。团队可将非结构化业务文档、车书手册、技术规范或常见问答沉淀到知识库中，由系统自动完成多模态解析、切块与向量索引，并在工作流或 MCP 协议中无缝调用。

![知识库列表界面](/images/knowledge/knowledge-bases-list.png)

## 知识库创建与模型绑定

在项目的「知识库」页面，点击 **创建知识库** 卡片进入新建流程：

1. **基本信息**：
   - **名称（必填）**：知识库唯一展示名称（如 `1030`、`车书手册库`）；
   - **标签（Tags）**：支持为知识库绑定多组语义标签，方便跨知识库联合过滤与检索分类；
   - **描述**：说明该知识库存储的内容范畴（如 `奔驰 E-Class 全系车书及车钥匙操作规范`）。
2. **底层模型绑定**：
   - **向量化模型（Embedding）**：指定用于将切块文本转换为高维向量的嵌入模型（如 `text-embedding-3-small`、`bge-large-zh` 等）；
   - **重排模型（Reranker，可选）**：用于对多路召回候选集进行交叉注意力打分的二次精排模型。

## 知识库管理工作台

点击任一知识库卡片即可进入详情页工作台：

![知识库详情工作台与文档列表](/images/knowledge/knowledge-base-detail.png)

### 1. 文件上传与入库配置
详情页中心区域提供大面积的文件拖拽上传区：
- **格式支持**：直接拖入或点击上传 PDF、Word（`.docx`）、PowerPoint（`.pptx`）、Excel（`.xlsx`）、Markdown（`.md`）、纯文本（`.txt`）以及扫描图片（`.png`, `.jpg`）；
- **去重策略**：同名且文件大小完全相同的文件系统会自动去重保留一份，避免重复切分与存储浪费。

### 2. 全局分块与清洗策略
在上传区下方，可直接配置该知识库切分文本的超参数：
- **分块大小（Chunk Size）**：每块最大字符数，系统默认推荐为 `1000` 字符；
- **分块重叠（Chunk Overlap）**：相邻块重叠的字符窗口，默认推荐为 `200` 字符，有效避免关键句被生硬截断导致的语义丢失；
- **清洗策略（Cleaning Strategy）**：
  - `STANDARD`（标准模式）：自动过滤空行、控制字符、乱码字符与多余的空白符；
  - `自定义规则`：弹出规则配置窗口，支持按正则过滤指定敏感字样、删除自定义页眉/页脚等。

### 3. 文档生命周期监控进度条
系统提供彩色的多状态进度条，实时展现入库状态分布：
- **绿色**：`可用`（处理完毕，已完成分块与向量化，可立即检索）；
- **黄色**：`分析中`（正在抽取文本结构、执行 OCR 视觉识别或语音转写）；
- **蓝色**：`向量化中`（正在调用嵌入模型生成向量并写入数据库）；
- **红色**：`异常`（文件损坏、模型调用超时等，悬停可查看具体错误日志）；
- **灰色**：`暂停处理`。

### 4. 文档列表与快捷操作
每个入库成功的文档以列表形式展现：
- 显示文件图标、文件名（如 `E-Class车书_钥匙.pdf`）、文件体积（`1.30 MB`）与上传时间戳；
- 状态标签（如绿色 `可用`）；
- **测试按钮**：一键弹出单文档检索测试沙箱，输入问题验证该文档内部的分块召回准确率；
- **操作菜单（`...`）**：支持重新解析、暂停处理与删除文档。
