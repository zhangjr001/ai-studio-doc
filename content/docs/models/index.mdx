「模型管理」是 Spark AI Studio 连接底层 AI 算力与基础设施的统一枢纽。平台支持将公有云商业大模型、聚合网关或本地私有化部署的开源模型（vLLM、Ollama 等）注册为统一的标准通道，供所有项目和工作流随需调度。

![模型管理控制台：四类模型体系与 API 管理](/images/settings/model-management.png)

## 四大模型能力矩阵

在项目或组织设置的「Models」选项卡中，模型被清晰划分为四种独立专业用途，不同业务组件严格消费对应类别的模型：

| 模型分类 | 服务组件与业务场景 | 典型模型代表 | 必要性说明 |
| -------- | ------------------ | ------------ | ---------- |
| **通用模型** | 工作流 Agent 智能体、意图分类器、LLM 语义护栏、AI 构建助手、测试会话 | `gemini-3.5-flash`, `gpt-4o`, `deepseek-chat`, `qwen-plus` | **核心必需**。驱动所有推理与对话能力 |
| **向量化模型** | 知识库文档分块向量化、向量查询沙箱、实时 KNN 语义检索 | `text-embedding-3-small`, `bge-large-zh`, `bge-m3` | **RAG 必需**。构建知识库时必选 |
| **多模态模型** | 知识库图片解析、PDF 扫描件 OCR 结构化提取、多模态问答 | `gpt-4o`, `qwen-vl-max`, `claude-3-5-sonnet` | 解析含图片、图表的非纯文本文件时必需 |
| **音频转写模型** | 知识库录音文件、会议语音转录与分块入库 | `whisper-1`, `sense-voice` | 上传音频文件构建知识库时必需 |

## 添加与配置模型

在相应模型类别的卡片右上角点击 **+ 添加** 按钮，或者点击顶部的 **API 管理**：

1. **选择供应商协议**：系统原生支持通用 OpenAI 兼容协议标准；
2. **填写接入通道参数**：

   ```yaml title="模型配置参数示例"
   模型分类: 通用模型
   模型名称: gemini-3.5-flash        # 界面下拉列表中显示的名称
   API 通道: OpenAI 兼容通道
   Base URL: https://api.openai.com/v1 # 推理服务地址（支持私有网关或内网地址）
   API Key: sk-xxxxxxxxxxxx           # 访问凭据（安全加密存储）
   模型标识(Model ID): gemini-3.5-flash # 实际向接口传递的真实模型名
   ```

3. **连通性校验**：填写完毕后建议点击「测试连接」，系统自动发送轻量探测请求验证网络通畅与鉴权有效；
4. **设为默认模型**：可在列表操作栏将某个模型标记为「默认」，后续新建 Agent 或知识库时将自动预填该模型。

## 适配多样化推理后端

得益于对 OpenAI 协议的良好支持，AI Studio 支持极度丰富的推理后端体系：

### 1. 公有云与商业 API
- **OpenAI 官方**（GPT-4o、text-embedding-3 等）；
- **Google Gemini**（经 OpenAI 兼容代理或原生通道）；
- **DeepSeek / 阿里百炼通义千问 / 智谱 GLM / 月之暗面 Kimi** 等主流国产云厂商。

### 2. 企业私有聚合网关
大型企业通常部署有内部 OneAPI、New API 或中转网关。只需将 `Base URL` 填入企业内网网关地址，即可实现统一的账单统计、配额管控与路由熔断。

### 3. 私有化算力与本地部署
对于敏感数据不出内网的场景，可通过以下方式部署开源大模型：
- **vLLM**：生产级高性能推理引擎，启动时开启 `--host 0.0.0.0 --port 8000`；
- **Ollama**：轻量级本地测试环境，直接将 Base URL 指向 `http://127.0.0.1:11434/v1`；
- **Xinference / FastChat**：支持跨节点大并发调度。

## 组织级共享与项目级隔离

AI Studio 支持灵活的多级配置继承机制：
- **组织级模型**：由组织管理员（Owner/Co-owner）统一配置，该组织下的所有项目均可无缝直接继承使用，降低配置维护成本；
- **项目级模型覆盖**：单个项目亦可配置项目专属的特定模型（例如特定微调模型或独立结算账号的 API Key），优先级高于组织级全局配置。
