---
title: 画布与节点
description: 工作流编辑器的节点类型、连线规则、变量引用与运行调试
---

工作流编辑器是一个画布式（canvas）可视化编排界面：左侧为节点面板，中间为画布，选中节点后在右侧配置面板编辑参数。

## 画布操作

- **拖拽添加**：从节点面板拖动节点到画布任意位置；
- **连线**：从节点输出端口拖到下一个节点的输入端口，形成执行顺序；
- **对齐与缩放**：支持框选、对齐吸附、画布缩放与居中；
- **撤销 / 重做**：编辑操作支持多步撤销。

<Callout type="tip">
  连线决定执行拓扑。分支节点之后的路径按条件求值结果执行；并行路径会同时执行，汇合节点等待全部上游完成。
</Callout>

## 节点类型

| 类别 | 节点 | 说明 |
| ---- | ---- | ---- |
| 流程控制 | 开始 / 结束 / 条件分支 / 循环 | 定义输入输出与执行拓扑 |
| 模型 | LLM | 调用对话模型，支持引用提示词模板与上下文变量 |
| 知识 | 知识库检索 | 按知识库检索相关内容，注入到提示词上下文 |
| 工具 | 工具调用 / MCP / HTTP 请求 / 代码执行 | 扩展外部能力 |
| 交互 | 变量赋值 / 输出 | 中间结果暂存与流式输出 |

## 变量引用

节点之间通过 `{{变量}}` 语法传递数据：

```text title="在 LLM 节点的提示词中引用上游输出"
用户问题：{{start.input}}

参考资料：
{{knowledge.results}}
```

- 开始节点定义的输入参数可以在任意下游节点引用；
- 每个节点的输出会以节点名（或节点 ID）为前缀注册到上下文中；
- 引用不存在的变量会在运行测试时给出明确报错。

## 运行与调试

1. 点击右上角**运行测试**，在测试面板输入模拟数据；
2. 画布上实时展示每个节点的执行状态（成功 / 失败 / 运行中）；
3. 点击已执行节点查看输入、输出与耗时；
4. 调试通过后点击**发布**生成正式版本。

## 共享聊天

发布后的工作流可以生成**共享聊天**链接：拿到链接的人无需登录即可在聊天界面使用该工作流，适合快速交付轻量 AI 应用。可在工作流设置中开启/关闭分享、限制访问时效。
