「模型管理」页面是所有 AI 能力的入口：对话、嵌入、重排、多模态四类模型在此统一注册，供工作流、知识库与 AI 构建调用。

## 模型分类

| 分类 | 服务于 | 必要性 |
| ---- | ------ | ------ |
| **对话模型（LLM）** | LLM 节点、AI 构建、共享聊天 | 核心，必需 |
| **嵌入模型（Embedding）** | 知识库向量化 | 使用 RAG 时必需 |
| **重排模型（Rerank）** | 检索结果精排 | 可选 |
| **多模态模型** | OCR-VL 文档解析、Whisper 语音转写 | 处理图片/音频文档时必需 |

## 添加模型

1. 进入「模型管理」，点击**添加模型**；
2. 选择模型分类并填写：

   ```yaml title="对话模型示例"
   名称: gpt-4o           # 列表中显示的名称
   供应商/协议: OpenAI 兼容
   Base URL: https://api.example.com/v1
   API Key: your-api-key
   模型 ID: gpt-4o        # 调用时传给推理服务的真实 ID
   ```

3. 保存前使用**连通性测试**验证配置正确；
4. 保存后即可在节点与知识库配置的下拉列表中选择该模型。

## 兼容的推理服务

凡是兼容 OpenAI API 协议的服务均可接入，常见组合：

- **官方 API**：OpenAI、Anthropic（兼容层）、阿里百炼等；
- **聚合网关**：OneAPI、New API 等；
- **本地推理**：vLLM、Ollama、Xinference（自建 OpenAI 兼容端点）。

<Callout type="info">
  本地推理服务 Base URL 填内网地址即可，例如 Ollama 的 `http://ollama:11434/v1`（容器网络内）。API Key 可填任意占位值。
</Callout>

## 组织级与项目级配置

模型可在**组织级**统一配置供所有项目共享，也可在单个项目中配置私有模型（例如项目专属的微调模型）。节点选择模型时，两级配置合并展示，项目级优先。
